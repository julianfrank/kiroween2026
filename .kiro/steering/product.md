# Product: Scary Money Manager

A private personal money manager delivered as one HTML file for desktop Chrome, built for Kiroween 2026.

- **Who it is for:** people in India who want to keep their own books without handing bank logins or spending data to a server.
- **What it does:** the user describes money events in plain words in a chat on each tab. Chrome's on-device AI (Gemini Nano, via the Prompt API) proposes a double-entry Entry; the app validates it and does all the arithmetic, and the user confirms it on a Confirm Card.
- **Privacy:** everything stays in the browser. Every stored and exported value is encrypted with the session password; keys are opaque IDs.
- **Tabs:** Dashboard (two Sankeys and seven charts), Assets, Liabilities, Goals, Budgets, Daily Updates (the Ledger), Data and password.
- **Look:** the entry screens are a dark graveyard ("the crypt") with flying Kiro-style ghosts. The main app's theme follows Net Worth State (Light, Twilight, Dark), the header title is "My Money Manager" above zero and "Scary Money Manager" otherwise, and a ghost hand-writes a funny, true line about the user's situation.
- **Live app:** https://julianfrank.github.io/kiroween2026/
